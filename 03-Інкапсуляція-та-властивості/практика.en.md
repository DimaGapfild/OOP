# Practice Tasks for Chapter 3

**Task type:** protect an object's state: private attributes,
`@property`, validation in setters.

Requirements for **every** task:
1. internal data is "private" (`_x`);
2. invalid values are rejected (`ValueError`);
3. docstrings in the class and methods;
4. 3 checks using `assert` (including for `ValueError`).

---

### Task 3.1
A `BankAccount` class — an owner and a balance.
The balance is read-only (`@property`). Methods `deposit`, `withdraw`
(not below 0), `history()` returns a **copy** of the list of operations.

### Task 3.2
A `Temperature` class with a `celsius` property (the setter forbids values
below −273.15) and a computed `fahrenheit` (read and write).

### Task 3.3
A `Person` class — a name (non-empty, surrounding spaces are stripped)
and an age (0..150) as properties with validation. The property
`is_adult` is read-only.

### Task 3.4
A `Password` class — stores a **hash**, not the password.
Methods `set(new)` (min. 8 characters), `check(candidate)`.
The password cannot be read back.

### Task 3.5
A `Rectangle` class with side properties `width`, `height`
(positive only) and computed `area`, `perimeter`.

### Task 3.6
A `Thermostat` class — a target temperature from the range
`[min_t, max_t]`. The setter **clamps** the value to the range
instead of raising an error. A method `heating_needed(current)`.

### Task 3.7
An `Inventory` class — a warehouse. The internal "item → quantity" dictionary
is not directly accessible; methods `add(name, qty)`, `remove(name, qty)`
(not more than is in stock), `quantity(name)`, `items()` — a copy.

### Task 3.8
A `Student` class — an immutable `id` (read-only), a name (property)
and grades; `grades` returns a tuple (it cannot be changed from outside),
and grades are added only via `add_grade`.

### Task 3.9
A `Circle` class with a radius property and a **cached** area:
the area is recomputed only after the radius changes.
Add a computation counter `compute_count` to verify the cache.

### Task 3.10
An `Email` class — an address with validation in the setter
(exactly one `@`, non-empty parts, a dot in the domain).
The properties `user` and `domain` are read-only.

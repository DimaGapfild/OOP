# Practice Tasks for Chapter 7

**Task type:** design an abstraction (an abstract class or an interface)
and several implementations of it; client code depends only on the abstraction.

Requirements for **every** task:
1. the abstract class/interface cannot be instantiated directly (`TypeError`);
2. docstrings in classes;
3. a demonstration of working with different implementations;
4. 3 checks using `assert`.

---

### Task 7.1
`Shape(ABC)` with abstract `area()`, `perimeter()` and a regular
`describe()`. Implementations `Rect`, `Circle`. Check that `Shape()` raises `TypeError`.

### Task 7.2
Template method: `Report(ABC)` with a `build()` method (header + lines +
footer). Children `SalesReport` (a dictionary item → amount, the footer shows
the total) and `InventoryReport` (the default footer).

### Task 7.3
Interface `Storage(ABC)`: `save(key, value)`, `load(key)`
(`KeyError` if absent), `delete(key)`, `keys()`.
Implementations `MemoryStorage` and `CountingStorage` (a wrapper that counts
operations). A function `backup(src, dst)`.

### Task 7.4
`Vehicle(ABC)` with an abstract property `max_speed` and a method
`travel_time(km)`. Implementations: `Car`, `Bicycle`, `Plane`.

### Task 7.5
A `Drawable` `Protocol` with a `draw()` method. The classes `Circle`,
`Label` **do not inherit** `Drawable`. A function `render_all(items)`
draws only what matches the protocol.

### Task 7.6
Interface `Repository(ABC)`: `add(entity)`, `get(id)`, `all()`,
`remove(id)`. An `InMemoryRepository` implementation for the entity
`Student(id, name)`; a duplicate id → `ValueError`.

### Task 7.7
Interface `Logger(ABC)`: `log(level, msg)`. Implementations `ListLogger`
(stores in a list), `StreamLogger` (writes to a stream), `NullLogger`.
`OrderService(logger)` logs successful and failed orders.

### Task 7.8
Implement `Countdown(n)` on top of `collections.abc.Sequence`:
only `__len__` and `__getitem__` — iteration, `in`, `index`, `count`
must work "for free".

### Task 7.9
Plugins: `Plugin(ABC)` with abstract `name` and `run(data)`.
`PluginManager.register(cls)` accepts only subclasses of `Plugin`
(`TypeError` otherwise); `run_all(data)` applies the plugins in turn.

### Task 7.10
Two interfaces `Readable` (`read()`) and `Writable` (`write(text)`).
`MemoryFile` implements both, `ReadOnlyFile` only the first.
A function `copy(src, dst)` checks the types and raises `TypeError`
if the source is not `Readable` or the target is not `Writable`.

# Практичні завдання до розділу 7

**Тип завдань:** спроєктувати абстракцію (абстрактний клас або інтерфейс)
та кілька її реалізацій; клієнтський код залежить лише від абстракції.

Вимоги до **кожної** задачі:
1. абстрактний клас/інтерфейс не створюється напряму (`TypeError`);
2. docstring у класах;
3. демонстрація роботи з різними реалізаціями;
4. щонайменше 3 тести.

> **Інструменти для тестів.** Використовуйте стандартний інструмент своєї мови:
> - **Python** — `pytest` (`def test_...(): assert ...`) або вбудований `unittest`;
> - **JavaScript / TypeScript** — вбудовані `node:test` + `node:assert` (Node 18+) або `Jest` / `Vitest`;
> - **C++** — `GoogleTest` або `Catch2`; для швидких перевірок — `assert` із `<cassert>`.
>
> Порада: покрийте звичайний випадок, граничний (порожньо, нуль, межа) і некоректні дані.

---

### Задача 7.1
`Shape(ABC)` з абстрактними `area()`, `perimeter()` та звичайним
`describe()`. Реалізації `Rect`, `Circle`. Перевірити, що `Shape()` кидає `TypeError`.

### Задача 7.2
Шаблонний метод: `Report(ABC)` із методом `build()` (шапка + рядки +
підвал). Нащадки `SalesReport` (словник товар → сума, у підвалі —
разом) та `InventoryReport` (підвал за замовчуванням).

### Задача 7.3
Інтерфейс `Storage(ABC)`: `save(key, value)`, `load(key)`
(`KeyError`, якщо немає), `delete(key)`, `keys()`.
Реалізації `MemoryStorage` і `CountingStorage` (обгортка, рахує
операції). Функція `backup(src, dst)`.

### Задача 7.4
`Vehicle(ABC)` з абстрактною властивістю `max_speed` та методом
`travel_time(km)`. Реалізації: `Car`, `Bicycle`, `Plane`.

### Задача 7.5
`Protocol` `Drawable` з методом `draw()`. Класи `Circle`,
`Label` **не наслідують** `Drawable`. Функція `render_all(items)`
малює лише те, що відповідає протоколу.

### Задача 7.6
Інтерфейс `Repository(ABC)`: `add(entity)`, `get(id)`, `all()`,
`remove(id)`. Реалізація `InMemoryRepository` для сутності
`Student(id, name)`; дублікат id → `ValueError`.

### Задача 7.7
Інтерфейс `Logger(ABC)`: `log(level, msg)`. Реалізації `ListLogger`
(зберігає в списку), `StreamLogger` (пише в потік), `NullLogger`.
`OrderService(logger)` логує успішні й помилкові замовлення.

### Задача 7.8
Реалізувати `Countdown(n)` на основі `collections.abc.Sequence`:
лише `__len__` і `__getitem__` — обхід, `in`, `index`, `count`
повинні працювати «безкоштовно».

### Задача 7.9
Плагіни: `Plugin(ABC)` з абстрактними `name` і `run(data)`.
`PluginManager.register(cls)` приймає лише підкласи `Plugin`
(`TypeError` інакше); `run_all(data)` застосовує плагіни по черзі.

### Задача 7.10
Два інтерфейси `Readable` (`read()`) і `Writable` (`write(text)`).
`MemoryFile` реалізує обидва, `ReadOnlyFile` — лише перший.
Функція `copy(src, dst)` перевіряє типи й кидає `TypeError`,
якщо джерело не `Readable` або ціль не `Writable`.

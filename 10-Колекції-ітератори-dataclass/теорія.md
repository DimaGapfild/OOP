# Розділ 10. Колекції об'єктів, ітератори, dataclass

## 10.1 Класи даних

Багато класів — лише «контейнери даних»: поля, `__init__`, `__repr__`,
`__eq__`. Модуль `dataclasses` генерує їх автоматично:

**Python**

```python
from dataclasses import dataclass, field, asdict, replace

@dataclass
class Student:
    name: str
    group: str = "КН-21"                              # значення за замовчуванням
    grades: list[int] = field(default_factory=list)   # змінне значення — лише так!

s = Student("Коваль")
print(s)                       # Student(name='Коваль', group='КН-21', grades=[])
s == Student("Коваль")         # True — __eq__ порівнює поля
asdict(s)                      # {'name': 'Коваль', ...}
replace(s, group="КН-22")      # копія зі зміненим полем
```

**JavaScript** — аналога `@dataclass` немає; поля, копію та порівняння
пишуть вручну:

```js
class Student {
    constructor(name, group = "КН-21", grades = []) {
        Object.assign(this, { name, group, grades: [...grades] });
    }

    equals(other) {
        return JSON.stringify(this) === JSON.stringify(other);
    }

    with(changes) {                         // копія зі зміненим полем
        return Object.assign(new Student(this.name), this, changes);
    }
}

const s = new Student("Коваль");
s.equals(new Student("Коваль"));            // true
s.with({ group: "КН-22" });
```

**C++** — агрегатна `struct` + згенерований компілятором `operator==` (C++20):

```cpp
#include <string>
#include <vector>

struct Student {
    std::string name;
    std::string group = "КН-21";            // значення за замовчуванням
    std::vector<int> grades;                // у кожного об'єкта свій вектор

    bool operator==(const Student&) const = default;
};

Student s{"Коваль"};
s == Student{"Коваль"};                     // true — порівнюються поля
Student s2 = s;
s2.group = "КН-22";                         // копія зі зміненим полем
```

Корисні параметри:

| Параметр | Дія |
|----------|-----|
| `order=True` | генерує `<`, `<=`, `>`, `>=` (порівняння кортежів полів) |
| `frozen=True` | незмінний об'єкт: присвоєння кидає `FrozenInstanceError`; з `eq=True` стає **хешованим** |
| `slots=True` (3.10+) | економія пам'яті, швидший доступ |
| `field(default_factory=…)` | нове значення для кожного об'єкта |
| `field(compare=False)`, `field(repr=False)` | виключити поле з порівняння / виводу |
| `__post_init__` | валідація/обчислювані поля після автоматичного `__init__` |

**Python**

```python
@dataclass(frozen=True, order=True)
class Money:
    amount: int
    currency: str = "UAH"

    def __post_init__(self):
        if self.amount < 0:
            raise ValueError("сума не може бути від'ємною")
```

**JavaScript**

```js
class Money {
    constructor(amount, currency = "UAH") {
        if (amount < 0) throw new RangeError("сума не може бути від'ємною");
        this.amount = amount;
        this.currency = currency;
        Object.freeze(this);               // незмінний об'єкт
    }
}
```

**C++** — `const`-поля та згенерований `operator<=>` (усі порівняння):

```cpp
#include <compare>
#include <stdexcept>

struct Money {
    const int amount;
    const std::string currency;

    Money(int amount, std::string currency = "UAH")
        : amount(amount), currency(currency) {
        if (amount < 0) throw std::invalid_argument("сума не може бути від'ємною");
    }

    auto operator<=>(const Money&) const = default;   // ==, <, <=, >, >=
};
```

Змінний список як значення за замовчуванням (`items: list = []`)
заборонено — `ValueError` (це та сама пастка, що й у розділі 2).

Схожі засоби: `typing.NamedTuple` (незмінний кортеж із полями),
`enum.Enum` (набір іменованих констант).

## 10.2 Ітерований об'єкт і ітератор

| Поняття | Протокол | Приклад |
|---------|----------|---------|
| **Iterable** (ітерований) | має `__iter__()`, що повертає ітератор | список, рядок, файл |
| **Iterator** (ітератор) | має `__next__()` і `__iter__()` (повертає себе) | `iter(list)` |

Цикл `for x in obj` робить: `it = iter(obj)`, потім викликає `next(it)`,
доки не виникне `StopIteration`.

**Python**

```python
class Fibonacci:
    """Ітератор: одноразовий, зберігає стан."""
    def __init__(self, n):
        self.n, self.a, self.b, self.i = n, 0, 1, 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.i >= self.n:
            raise StopIteration
        self.i += 1
        value, self.a, self.b = self.a, self.b, self.a + self.b
        return value
```

**JavaScript** — ітератор = об'єкт із методом `next()`, що повертає
`{ value, done }`:

```js
class Fibonacci {
    constructor(n) {
        Object.assign(this, { n, a: 0, b: 1, i: 0 });
    }

    [Symbol.iterator]() {
        return this;
    }

    next() {
        if (this.i >= this.n) return { done: true, value: undefined };
        this.i += 1;
        const value = this.a;
        [this.a, this.b] = [this.b, this.a + this.b];
        return { done: false, value };
    }
}

for (const x of new Fibonacci(5)) console.log(x);   // 0 1 1 2 3
```

**C++** — для range-`for` потрібні `begin()`/`end()` і ітератор з
`operator*`, `operator++`, `operator!=`:

```cpp
class Fibonacci {
public:
    explicit Fibonacci(int n) : n(n) {}

    struct Iterator {
        long a, b;
        int i;
        long operator*() const { return a; }
        Iterator& operator++() { long t = a + b; a = b; b = t; ++i; return *this; }
        bool operator!=(const Iterator& o) const { return i != o.i; }
    };

    Iterator begin() const { return {0, 1, 0}; }
    Iterator end() const   { return {0, 0, n}; }

private:
    int n;
};

for (long x : Fibonacci(5)) std::cout << x << " ";  // 0 1 1 2 3
```

Ітератор **вичерпується**. Щоб колекцію можна було обходити
багато разів, `__iter__` має повертати **новий** ітератор
(наприклад, генератор).

## 10.3 Генератори

Функція з `yield` повертає **ліниве** послідовне значення — обчислення
відбувається за потреби, пам'ять не витрачається на всю послідовність:

**Python**

```python
def primes():
    found = []
    n = 2
    while True:                         # нескінченна послідовність
        if all(n % p for p in found):
            found.append(n)
            yield n
        n += 1

from itertools import islice
list(islice(primes(), 5))               # [2, 3, 5, 7, 11]
```

**JavaScript** — генераторна функція `function*`:

```js
function* primes() {
    const found = [];
    for (let n = 2; ; n++) {                // нескінченна послідовність
        if (found.every((p) => n % p !== 0)) {
            found.push(n);
            yield n;
        }
    }
}

const first5 = [];
for (const p of primes()) {
    if (first5.push(p) === 5) break;
}                                           // [2, 3, 5, 7, 11]
```

**C++23** — `std::generator`:

```cpp
#include <algorithm>
#include <generator>
#include <ranges>
#include <vector>

std::generator<int> primes() {
    std::vector<int> found;
    for (int n = 2; ; ++n) {                // нескінченна послідовність
        if (std::ranges::all_of(found, [n](int p) { return n % p != 0; })) {
            found.push_back(n);
            co_yield n;
        }
    }
}

for (int p : primes() | std::views::take(5)) std::cout << p << " ";
```

`yield from other` — делегування іншому генератору (корисно для
рекурсивних обходів дерев). Генераторний вираз: `(x * x for x in range(10))`.

## 10.4 Власні колекції

Успадковуйтесь від `collections.abc`, реалізуйте мінімум — решту
отримаєте безкоштовно:

| Базовий клас | Реалізувати | Отримати |
|--------------|-------------|----------|
| `Sequence` | `__len__`, `__getitem__` | `__iter__`, `__contains__`, `index`, `count`, `reversed` |
| `MutableMapping` | `__getitem__`, `__setitem__`, `__delitem__`, `__iter__`, `__len__` | `keys`, `items`, `values`, `get`, `pop`, `update`, `==` |

Власний контейнер — це клас, що **інкапсулює** внутрішню структуру
(список, словник, дерево) і підтримує **інваріант** (наприклад,
відсортованість).

## 10.5 Сортування та групування

**Python**

```python
from operator import attrgetter
from itertools import groupby

sorted(people, key=attrgetter("dept", "name"))             # за кількома полями
sorted(people, key=lambda p: (-p.salary, p.name))          # спадання + тайбрейк

people.sort(key=attrgetter("dept"))                        # groupby потребує відсортованих!
{d: list(g) for d, g in groupby(people, key=attrgetter("dept"))}
```

**JavaScript**

```js
people.sort((a, b) => a.dept.localeCompare(b.dept) || a.name.localeCompare(b.name));
people.sort((a, b) => b.salary - a.salary || a.name.localeCompare(b.name));

Object.groupBy(people, (p) => p.dept);      // { IT: [...], HR: [...] } — сортувати не треба
```

**C++**

```cpp
#include <algorithm>
#include <map>
#include <tuple>

std::ranges::sort(people, {}, [](const Person& p) {
    return std::tie(p.dept, p.name);        // за кількома полями
});
std::ranges::sort(people, [](const Person& a, const Person& b) {
    return std::tie(b.salary, a.name) < std::tie(a.salary, b.name);
});

std::map<std::string, std::vector<Person>> byDept;
for (const auto& p : people) byDept[p.dept].push_back(p);
```

> **Пастка JavaScript: `sort()` за замовчуванням порівнює рядки.**
>
> ```python
> sorted([10, 9, 1])       # [1, 9, 10]
> ```
>
> ```js
> [10, 9, 1].sort();                 // [1, 10, 9] — порівняння як рядків!
> [10, 9, 1].sort((a, b) => a - b);  // [1, 9, 10] — правильно
> ```
>
> ```cpp
> std::vector v{10, 9, 1};
> std::ranges::sort(v);              // {1, 9, 10} — за operator<
> ```
>
> Також: `sort()` у JS і `list.sort()` у Python змінюють масив **на
> місці**; копію повертають `sorted()` у Python і `toSorted()` у JS.

## 10.6 Enum

**Python**

```python
from enum import Enum, IntEnum

class Status(Enum):
    TODO = "todo"
    DONE = "done"

class Priority(IntEnum):          # зі значеннями-числами, що порівнюються
    LOW = 1
    HIGH = 3

Status("todo") is Status.TODO     # пошук за значенням
Status["DONE"]                    # пошук за іменем
Priority.HIGH > Priority.LOW      # True
```

**JavaScript** — заморожений об'єкт констант:

```js
const Status = Object.freeze({ TODO: "todo", DONE: "done" });
const Priority = Object.freeze({ LOW: 1, HIGH: 3 });

Object.values(Status).includes("todo");    // пошук за значенням
Status["DONE"];                            // пошук за іменем
Priority.HIGH > Priority.LOW;              // true
```

**C++** — `enum class` (без неявного перетворення на `int`):

```cpp
enum class Status { Todo, Done };
enum class Priority { Low = 1, High = 3 };

Status s = Status::Todo;
Priority::High > Priority::Low;            // true — однакові enum порівнюються
// int x = Status::Done;                   // помилка: потрібен static_cast
```

> **Різниця між мовами: описка в імені константи.**
>
> ```python
> Status.TODOO             # AttributeError
> ```
>
> ```js
> Status.TODOO;            // undefined — без помилки
> ```
>
> ```cpp
> Status::Todoo;           // помилка компіляції
> ```

## 10.7 Порівняння з іншими мовами

| Можливість | Python | JavaScript | C++ |
|------------|--------|-----------|-----|
| Клас даних | `@dataclass` | немає (звичайний клас, `Object.freeze`, `structuredClone`) | `struct` + `operator==`, `std::tie`; C++20 `= default` |
| Незмінність | `frozen=True` | `Object.freeze` | `const` |
| Ітератор | `__iter__`/`__next__` | `[Symbol.iterator]()` → `{ next() }` | `begin()`/`end()`, `operator++`, `operator*` |
| Генератор | `yield` | `function*` + `yield` | C++23 `std::generator`; раніше — вручну |
| Enum | `enum.Enum` | `Object.freeze({...})` | `enum class` |
| Хеш для set/dict | `__hash__` | `Map` за посиланням (власних хешів немає) | `std::hash` + `operator==` |

# Chapter 10. Collections of Objects, Iterators, dataclass

## 10.1 Data Classes: `@dataclass`

Many classes are just "data containers": fields, `__init__`, `__repr__`,
`__eq__`. The `dataclasses` module generates them automatically:

```python
from dataclasses import dataclass, field, asdict, replace

@dataclass
class Student:
    name: str
    group: str = "CS-21"                              # a default value
    grades: list[int] = field(default_factory=list)   # a mutable value — only this way!

s = Student("Koval")
print(s)                       # Student(name='Koval', group='CS-21', grades=[])
s == Student("Koval")          # True — __eq__ compares the fields
asdict(s)                      # {'name': 'Koval', ...}
replace(s, group="CS-22")      # a copy with one field changed
```

Useful parameters:

| Parameter | Effect |
|-----------|--------|
| `order=True` | generates `<`, `<=`, `>`, `>=` (comparison of tuples of fields) |
| `frozen=True` | an immutable object: assignment raises `FrozenInstanceError`; with `eq=True` it becomes **hashable** |
| `slots=True` (3.10+) | saves memory, faster access |
| `field(default_factory=…)` | a new value for each object |
| `field(compare=False)`, `field(repr=False)` | exclude a field from comparison / output |
| `__post_init__` | validation/computed fields after the automatic `__init__` |

```python
@dataclass(frozen=True, order=True)
class Money:
    amount: int
    currency: str = "UAH"

    def __post_init__(self):
        if self.amount < 0:
            raise ValueError("the amount cannot be negative")
```

A mutable list as a default value (`items: list = []`)
is forbidden — `ValueError` (this is the same trap as in chapter 2).

Similar tools: `typing.NamedTuple` (an immutable tuple with fields),
`enum.Enum` (a set of named constants).

## 10.2 Iterable and Iterator

| Concept | Protocol | Example |
|---------|----------|---------|
| **Iterable** | has `__iter__()` that returns an iterator | list, string, file |
| **Iterator** | has `__next__()` and `__iter__()` (returns itself) | `iter(list)` |

The loop `for x in obj` does: `it = iter(obj)`, then calls `next(it)`
until `StopIteration` is raised.

```python
class Fibonacci:
    """An iterator: single-use, keeps state."""
    def __init__(self, n):
        self.n, self.a, self.b, self.i = n, 0, 1, 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.i >= self.n:
            raise StopIteration
        self.i += 1
        value, self.a, self.b = self.a, self.b, self.a + self.b
        return value
```

An iterator **gets exhausted**. For a collection to be traversable
many times, `__iter__` must return a **new** iterator
(for example, a generator).

## 10.3 Generators

A function with `yield` returns a **lazy** sequence of values — computation
happens on demand, and no memory is spent on the whole sequence:

```python
def primes():
    found = []
    n = 2
    while True:                         # an infinite sequence
        if all(n % p for p in found):
            found.append(n)
            yield n
        n += 1

from itertools import islice
list(islice(primes(), 5))               # [2, 3, 5, 7, 11]
```

`yield from other` delegates to another generator (useful for
recursive tree traversals). A generator expression: `(x * x for x in range(10))`.

## 10.4 Custom Collections

Inherit from `collections.abc`, implement the minimum — and get the rest
for free:

| Base class | Implement | Get |
|------------|-----------|-----|
| `Sequence` | `__len__`, `__getitem__` | `__iter__`, `__contains__`, `index`, `count`, `reversed` |
| `MutableMapping` | `__getitem__`, `__setitem__`, `__delitem__`, `__iter__`, `__len__` | `keys`, `items`, `values`, `get`, `pop`, `update`, `==` |

A custom container is a class that **encapsulates** an internal structure
(a list, a dictionary, a tree) and maintains an **invariant** (for example,
being sorted).

## 10.5 Sorting, Grouping, `key`

```python
from operator import attrgetter
from itertools import groupby

sorted(people, key=attrgetter("dept", "name"))             # by several fields
sorted(people, key=lambda p: (-p.salary, p.name))          # descending + tie-breaker

people.sort(key=attrgetter("dept"))                        # groupby needs sorted input!
{d: list(g) for d, g in groupby(people, key=attrgetter("dept"))}
```

## 10.6 Enum

```python
from enum import Enum, IntEnum

class Status(Enum):
    TODO = "todo"
    DONE = "done"

class Priority(IntEnum):          # with numeric, comparable values
    LOW = 1
    HIGH = 3

Status("todo") is Status.TODO     # lookup by value
Status["DONE"]                    # lookup by name
Priority.HIGH > Priority.LOW      # True
```

## 10.7 Comparison with Other Languages

| Feature | Python | JavaScript | C++ |
|---------|--------|-----------|-----|
| Data class | `@dataclass` | none (a regular class, `Object.freeze`, `structuredClone`) | `struct` + `operator==`, `std::tie`; C++20 `= default` |
| Immutability | `frozen=True` | `Object.freeze` | `const` |
| Iterator | `__iter__`/`__next__` | `[Symbol.iterator]()` → `{ next() }` | `begin()`/`end()`, `operator++`, `operator*` |
| Generator | `yield` | `function*` + `yield` | C++23 `std::generator`; before that — by hand |
| Enum | `enum.Enum` | `Object.freeze({...})` | `enum class` |
| Hash for set/dict | `__hash__` | `Map` by reference (no custom hashes) | `std::hash` + `operator==` |

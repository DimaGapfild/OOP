# Chapter 10. Collections of Objects, Iterators, dataclass

## 10.1 Data Classes

Many classes are just "data containers": fields, `__init__`, `__repr__`,
`__eq__`. The `dataclasses` module generates them automatically:

**Python**

```python
from dataclasses import dataclass, field, asdict, replace

@dataclass
class Student:
    name: str
    group: str = "CS-21"                              # a default value
    grades: list[int] = field(default_factory=list)   # a mutable value — only this way!

s = Student("Koval")
print(s)                       # Student(name='Koval', group='CS-21', grades=[])
s == Student("Koval")          # True — __eq__ compares the fields
asdict(s)                      # {'name': 'Koval', ...}
replace(s, group="CS-22")      # a copy with one field changed
```

**JavaScript** — there is no `@dataclass` equivalent; fields, copying
and comparison are written by hand:

```js
class Student {
    constructor(name, group = "CS-21", grades = []) {
        Object.assign(this, { name, group, grades: [...grades] });
    }

    equals(other) {
        return JSON.stringify(this) === JSON.stringify(other);
    }

    with(changes) {                         // a copy with one field changed
        return Object.assign(new Student(this.name), this, changes);
    }
}

const s = new Student("Koval");
s.equals(new Student("Koval"));             // true
s.with({ group: "CS-22" });
```

**C++** — an aggregate `struct` + a compiler-generated `operator==` (C++20):

```cpp
#include <string>
#include <vector>

struct Student {
    std::string name;
    std::string group = "CS-21";            // a default value
    std::vector<int> grades;                // each object has its own vector

    bool operator==(const Student&) const = default;
};

Student s{"Koval"};
s == Student{"Koval"};                      // true — the fields are compared
Student s2 = s;
s2.group = "CS-22";                         // a copy with one field changed
```

Useful parameters:

| Parameter | Effect |
|-----------|--------|
| `order=True` | generates `<`, `<=`, `>`, `>=` (comparison of tuples of fields) |
| `frozen=True` | an immutable object: assignment raises `FrozenInstanceError`; with `eq=True` it becomes **hashable** |
| `slots=True` (3.10+) | saves memory, faster access |
| `field(default_factory=…)` | a new value for each object |
| `field(compare=False)`, `field(repr=False)` | exclude a field from comparison / output |
| `__post_init__` | validation/computed fields after the automatic `__init__` |

**Python**

```python
@dataclass(frozen=True, order=True)
class Money:
    amount: int
    currency: str = "UAH"

    def __post_init__(self):
        if self.amount < 0:
            raise ValueError("the amount cannot be negative")
```

**JavaScript**

```js
class Money {
    constructor(amount, currency = "UAH") {
        if (amount < 0) throw new RangeError("the amount cannot be negative");
        this.amount = amount;
        this.currency = currency;
        Object.freeze(this);               // an immutable object
    }
}
```

**C++** — `const` fields and a generated `operator<=>` (all comparisons):

```cpp
#include <compare>
#include <stdexcept>

struct Money {
    const int amount;
    const std::string currency;

    Money(int amount, std::string currency = "UAH")
        : amount(amount), currency(currency) {
        if (amount < 0) throw std::invalid_argument("the amount cannot be negative");
    }

    auto operator<=>(const Money&) const = default;   // ==, <, <=, >, >=
};
```

A mutable list as a default value (`items: list = []`)
is forbidden — `ValueError` (this is the same trap as in chapter 2).

Similar tools: `typing.NamedTuple` (an immutable tuple with fields),
`enum.Enum` (a set of named constants).

## 10.2 Iterable and Iterator

| Concept | Protocol | Example |
|---------|----------|---------|
| **Iterable** | has `__iter__()` that returns an iterator | list, string, file |
| **Iterator** | has `__next__()` and `__iter__()` (returns itself) | `iter(list)` |

The loop `for x in obj` does: `it = iter(obj)`, then calls `next(it)`
until `StopIteration` is raised.

**Python**

```python
class Fibonacci:
    """An iterator: single-use, keeps state."""
    def __init__(self, n):
        self.n, self.a, self.b, self.i = n, 0, 1, 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.i >= self.n:
            raise StopIteration
        self.i += 1
        value, self.a, self.b = self.a, self.b, self.a + self.b
        return value
```

**JavaScript** — an iterator is an object with a `next()` method that
returns `{ value, done }`:

```js
class Fibonacci {
    constructor(n) {
        Object.assign(this, { n, a: 0, b: 1, i: 0 });
    }

    [Symbol.iterator]() {
        return this;
    }

    next() {
        if (this.i >= this.n) return { done: true, value: undefined };
        this.i += 1;
        const value = this.a;
        [this.a, this.b] = [this.b, this.a + this.b];
        return { done: false, value };
    }
}

for (const x of new Fibonacci(5)) console.log(x);   // 0 1 1 2 3
```

**C++** — range-`for` needs `begin()`/`end()` and an iterator with
`operator*`, `operator++`, `operator!=`:

```cpp
class Fibonacci {
public:
    explicit Fibonacci(int n) : n(n) {}

    struct Iterator {
        long a, b;
        int i;
        long operator*() const { return a; }
        Iterator& operator++() { long t = a + b; a = b; b = t; ++i; return *this; }
        bool operator!=(const Iterator& o) const { return i != o.i; }
    };

    Iterator begin() const { return {0, 1, 0}; }
    Iterator end() const   { return {0, 0, n}; }

private:
    int n;
};

for (long x : Fibonacci(5)) std::cout << x << " ";  // 0 1 1 2 3
```

An iterator **gets exhausted**. For a collection to be traversable
many times, `__iter__` must return a **new** iterator
(for example, a generator).

## 10.3 Generators

A function with `yield` returns a **lazy** sequence of values — computation
happens on demand, and no memory is spent on the whole sequence:

**Python**

```python
def primes():
    found = []
    n = 2
    while True:                         # an infinite sequence
        if all(n % p for p in found):
            found.append(n)
            yield n
        n += 1

from itertools import islice
list(islice(primes(), 5))               # [2, 3, 5, 7, 11]
```

**JavaScript** — a generator function `function*`:

```js
function* primes() {
    const found = [];
    for (let n = 2; ; n++) {                // an infinite sequence
        if (found.every((p) => n % p !== 0)) {
            found.push(n);
            yield n;
        }
    }
}

const first5 = [];
for (const p of primes()) {
    if (first5.push(p) === 5) break;
}                                           // [2, 3, 5, 7, 11]
```

**C++23** — `std::generator`:

```cpp
#include <algorithm>
#include <generator>
#include <ranges>
#include <vector>

std::generator<int> primes() {
    std::vector<int> found;
    for (int n = 2; ; ++n) {                // an infinite sequence
        if (std::ranges::all_of(found, [n](int p) { return n % p != 0; })) {
            found.push_back(n);
            co_yield n;
        }
    }
}

for (int p : primes() | std::views::take(5)) std::cout << p << " ";
```

`yield from other` delegates to another generator (useful for
recursive tree traversals). A generator expression: `(x * x for x in range(10))`.

## 10.4 Custom Collections

Inherit from `collections.abc`, implement the minimum — and get the rest
for free:

| Base class | Implement | Get |
|------------|-----------|-----|
| `Sequence` | `__len__`, `__getitem__` | `__iter__`, `__contains__`, `index`, `count`, `reversed` |
| `MutableMapping` | `__getitem__`, `__setitem__`, `__delitem__`, `__iter__`, `__len__` | `keys`, `items`, `values`, `get`, `pop`, `update`, `==` |

A custom container is a class that **encapsulates** an internal structure
(a list, a dictionary, a tree) and maintains an **invariant** (for example,
being sorted).

## 10.5 Sorting and Grouping

**Python**

```python
from operator import attrgetter
from itertools import groupby

sorted(people, key=attrgetter("dept", "name"))             # by several fields
sorted(people, key=lambda p: (-p.salary, p.name))          # descending + tie-breaker

people.sort(key=attrgetter("dept"))                        # groupby needs sorted input!
{d: list(g) for d, g in groupby(people, key=attrgetter("dept"))}
```

**JavaScript**

```js
people.sort((a, b) => a.dept.localeCompare(b.dept) || a.name.localeCompare(b.name));
people.sort((a, b) => b.salary - a.salary || a.name.localeCompare(b.name));

Object.groupBy(people, (p) => p.dept);      // { IT: [...], HR: [...] } — no sorting needed
```

**C++**

```cpp
#include <algorithm>
#include <map>
#include <tuple>

std::ranges::sort(people, {}, [](const Person& p) {
    return std::tie(p.dept, p.name);        // by several fields
});
std::ranges::sort(people, [](const Person& a, const Person& b) {
    return std::tie(b.salary, a.name) < std::tie(a.salary, b.name);
});

std::map<std::string, std::vector<Person>> byDept;
for (const auto& p : people) byDept[p.dept].push_back(p);
```

> **JavaScript trap: `sort()` compares strings by default.**
>
> ```python
> sorted([10, 9, 1])       # [1, 9, 10]
> ```
>
> ```js
> [10, 9, 1].sort();                 // [1, 10, 9] — compared as strings!
> [10, 9, 1].sort((a, b) => a - b);  // [1, 9, 10] — correct
> ```
>
> ```cpp
> std::vector v{10, 9, 1};
> std::ranges::sort(v);              // {1, 9, 10} — by operator<
> ```
>
> Also: JS `sort()` and Python `list.sort()` change the array **in
> place**; a copy is returned by `sorted()` in Python and `toSorted()` in JS.

## 10.6 Enum

**Python**

```python
from enum import Enum, IntEnum

class Status(Enum):
    TODO = "todo"
    DONE = "done"

class Priority(IntEnum):          # with numeric, comparable values
    LOW = 1
    HIGH = 3

Status("todo") is Status.TODO     # lookup by value
Status["DONE"]                    # lookup by name
Priority.HIGH > Priority.LOW      # True
```

**JavaScript** — a frozen object of constants:

```js
const Status = Object.freeze({ TODO: "todo", DONE: "done" });
const Priority = Object.freeze({ LOW: 1, HIGH: 3 });

Object.values(Status).includes("todo");    // lookup by value
Status["DONE"];                            // lookup by name
Priority.HIGH > Priority.LOW;              // true
```

**C++** — `enum class` (no implicit conversion to `int`):

```cpp
enum class Status { Todo, Done };
enum class Priority { Low = 1, High = 3 };

Status s = Status::Todo;
Priority::High > Priority::Low;            // true — values of the same enum compare
// int x = Status::Done;                   // error: static_cast is required
```

> **Language difference: a typo in a constant name.**
>
> ```python
> Status.TODOO             # AttributeError
> ```
>
> ```js
> Status.TODOO;            // undefined — no error
> ```
>
> ```cpp
> Status::Todoo;           // compile error
> ```

## 10.7 Comparison with Other Languages

| Feature | Python | JavaScript | C++ |
|---------|--------|-----------|-----|
| Data class | `@dataclass` | none (a regular class, `Object.freeze`, `structuredClone`) | `struct` + `operator==`, `std::tie`; C++20 `= default` |
| Immutability | `frozen=True` | `Object.freeze` | `const` |
| Iterator | `__iter__`/`__next__` | `[Symbol.iterator]()` → `{ next() }` | `begin()`/`end()`, `operator++`, `operator*` |
| Generator | `yield` | `function*` + `yield` | C++23 `std::generator`; before that — by hand |
| Enum | `enum.Enum` | `Object.freeze({...})` | `enum class` |
| Hash for set/dict | `__hash__` | `Map` by reference (no custom hashes) | `std::hash` + `operator==` |

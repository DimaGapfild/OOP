# Practice Tasks for Chapter 10

**Task type:** data classes, iterators, generators, and custom collections.

Requirements for **every** task:
1. where appropriate — `@dataclass` (with suitable parameters);
2. docstrings in classes and functions;
3. generators must not build the whole list up front;
4. 3 checks using `assert`.

---

### Task 10.1
A `@dataclass(order=True)` `Point(x, y)` and `Student(name, group="CS-21",
grades=list)`. Show the automatic `__eq__`, `__repr__`,
sorting of points, `asdict` and `replace`.

### Task 10.2
An immutable `@dataclass(frozen=True)` `Money(amount, currency="UAH")`:
validation in `__post_init__`, a method `add(other)` returns a new
object. Prove hashability (a set, a dictionary key) and the error
when trying to change a field.

### Task 10.3
A cart: a `@dataclass` `Cart` with a list of items
(`default_factory`), methods `add(name, price, qty)`, `total()`.
Prove that two carts do not share a list; show that
`items: list = []` is forbidden in a dataclass.

### Task 10.4
An iterator `Fibonacci(n)` (the first n numbers, `__iter__`/`__next__`) and
a repeatedly iterable class `Countdown(n)`, where `__iter__`
creates a new traversal each time. Prove the "exhaustion" of the first and
the repeatability of the second.

### Task 10.5
Generators: `chunks(seq, n)`, `windows(seq, k)`, `take(iterable, n)`,
an infinite `primes()`. Show laziness (a generator computes nothing
until it is iterated).

### Task 10.6
A `SortedList` collection: always sorted, `add`, `remove`
(`ValueError` if absent), `__contains__` using binary search,
`__len__`, `__getitem__`, `__iter__`, `__repr__`.

### Task 10.7
A binary search tree `BST`: `insert`, `in`, `len`, `height()`,
a left-to-right traversal via a **generator** (`yield from`), `min`, `max`.

### Task 10.8
`Status(Enum)` (`todo`, `doing`, `done`) and `Priority(IntEnum)`.
A `@dataclass` `Task(title, priority, status)`; methods `advance()`,
functions `by_status(tasks, status)` and `next_task(tasks)` (the highest
priority among unfinished).

### Task 10.9
A `@dataclass` `Employee(name, dept, salary)`. Functions: sorting
by department and by salary descending, `group_by(items, key)`,
`top_n(items, n)`, `dept_totals(items)`.

### Task 10.10
An `Inventory` class based on `collections.abc.MutableMapping`
(`sku → quantity`): check that the quantity is a non-negative integer;
plus `total()`. Show that `get`, `pop`, `update`,
`items`, `==` work "for free".

# Об'єктно-орієнтоване програмування

Навчальний курс (продовження курсу «Алгоритмізація та програмування»).
Мова реалізації — **Python 3**.

## Структура

Кожен розділ — окрема папка з файлами:

| Файл | Призначення |
|------|-------------|
| `теорія.md` / `теорія.en.md` | конспект лекції: поняття, синтаксис, приклади |
| `практика.md` / `практика.en.md` | 10 однотипних задач одного рівня складності |
| `проєкт.md` / `проєкт.en.md` | (лише розділ 12) специфікація підсумкового проєкту, етапи та критерії оцінювання |

## Програма курсу

| № | Розділ |
|---|--------|
| 01 | Класи та об'єкти |
| 02 | Конструктори, атрибути, методи |
| 03 | Інкапсуляція та властивості |
| 04 | Магічні методи та перевантаження операторів |
| 05 | Успадкування |
| 06 | Поліморфізм |
| 07 | Абстракція та інтерфейси |
| 08 | Композиція та агрегація |
| 09 | Власні винятки та контракти |
| 10 | Колекції об'єктів, ітератори, dataclass |
| 11 | UML та принципи SOLID |
| 12 | Патерни проєктування та підсумковий проєкт |

## Як працювати з матеріалом

1. Прочитати `теорія.md`, повторити приклади в інтерпретаторі.
2. Виконати всі 10 задач із `практика.md` самостійно.

## Критерії оцінювання практичної роботи

| Бали | Вимоги |
|------|--------|
| 5 | усі 10 задач, код читабельний, крайні випадки враховані |
| 4 | 8–9 задач або дрібні недоліки в оформленні |
| 3 | 6–7 задач, базова правильність |
| 2 | 4–5 задач |
| 1 | менше 4 задач |

## Чистий код: базові вимоги

Кожен розв'язок, незалежно від мови, має відповідати цим правилам.

### Обмеження розміру

| Що | Ліміт |
|----|-------|
| Файл | ≤ 100 рядків |
| Функція / метод | ≤ 20 рядків |
| Клас | ≤ 10 публічних методів |
| Параметри функції | ≤ 3 |
| Глибина вкладеності (`if` / `for` / `while`) | ≤ 3 рівні |
| Довжина рядка | ≤ 80 символів (≤ 79 для Python, за PEP 8) |

Якщо ліміт перевищено — розділіть код: винесіть клас в окремий файл, виділіть допоміжний метод або об'єднайте параметри в об'єкт.

### Правила

1. **Змістовні імена.** Ім'я пояснює, що це або що воно робить (`total_price`, а не `tp`). Класи — іменники, методи — дієслова, булеві значення звучать як питання (`is_empty`, `has_debt`).
2. **Одна відповідальність.** Функція робить одну річ; клас має одну причину для змін. Бажано — один клас на файл.
3. **Ранній вихід.** Спершу обробіть некоректні випадки й поверніться, замість того щоб загортати основну логіку в глибокі `if` / `else`.
4. **Без дублювання (DRY).** Повторюваний код виносьте у функцію чи метод.
5. **Без «магічних чисел».** Використовуйте іменовані константи (`MAX_SPEED = 120`).
6. **Без глобального змінюваного стану.** Передавайте дані через параметри та атрибути об'єктів.
7. **Коментарі пояснюють *чому*, а не *що*.** Якщо код незрозумілий без коментаря — спершу перейменуйте або спростіть його.
8. **Зрозуміла обробка помилок.** Кидайте винятки замість повернення спеціальних кодів. Не «ковтайте» помилки мовчки.
9. **Єдине форматування.** Дотримуйтеся стилю своєї мови: [PEP 8](https://peps.python.org/pep-0008/) для Python, [Google JavaScript Style Guide](https://google.github.io/styleguide/jsguide.html) для JS, [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) для C++.
10. **Без мертвого коду.** Видаляйте невикористані змінні, функції, імпорти та закоментований код.

Джерело: правила спираються на книгу Robert C. Martin, [*Clean Code: A Handbook of Agile Software Craftsmanship*](https://www.informit.com/store/clean-code-a-handbook-of-agile-software-craftsmanship-9780132350884) (Prentice Hall, 2008).

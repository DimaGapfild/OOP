# Practice Tasks for Chapter 5

**Task type:** build a class hierarchy using `super()` and
method overriding.

Requirements for **every** task:
1. children call the parent's constructor via `super()`;
2. method overrides that extend (`super().method()`) where appropriate;
3. a docstring in every class;
4. at least 3 tests (including a type check: `isinstance` / `instanceof` / `dynamic_cast`).

> **Testing tools.** Use the standard tool for your language:
> - **Python** — `pytest` (`def test_...(): assert ...`) or the built-in `unittest`;
> - **JavaScript / TypeScript** — the built-in `node:test` + `node:assert` (Node 18+), or `Jest` / `Vitest`;
> - **C++** — `GoogleTest` or `Catch2`; for quick checks, `assert` from `<cassert>`.
>
> Tip: cover a normal case, an edge case (empty, zero, limit), and invalid input.

---

### Task 5.1
An `Animal` class (name, method `speak()`), children `Dog`, `Cat`, `Cow`.
The `intro()` method in the base class uses the child's `speak()`.

### Task 5.2
A `Vehicle` class (brand, speed, `wheels()`), children `Car`
(4 wheels), `Bike` (2), `Truck` (6, plus a load capacity).
A `describe()` method in each.

### Task 5.3
An `Employee` class (name, rate, `pay()`), children `Manager`
(adds a bonus) and `Developer` (adds a level-based allowance).
A function `total_payroll(list)`.

### Task 5.4
The hierarchy `Shape` → `Rectangle` → `Square`. `Square` calls the
`Rectangle` constructor with equal sides. A method `area()`.

### Task 5.5
An `Account` class (balance, `withdraw`), children `SavingsAccount`
(interest rate, `add_interest()`) and `CheckingAccount` (overdraft limit,
an overridden `withdraw`).

### Task 5.6
`Person` (surname, age) → `Student` (group), `Teacher` (department).
`info()` extends the base method. A function returns all students
from a list of people, using `isinstance`.

### Task 5.7
Multiple inheritance: `Flyer.move()`, `Swimmer.move()`,
`Walker.move()` and `Duck(Flyer, Swimmer, Walker)`.
Show the MRO and use `super()` in a chain so that
`Duck.move()` returns all ways of moving.

### Task 5.8
Mixins `ReprMixin` (an automatic `__repr__` based on attributes)
and `EqMixin` (`__eq__` based on attributes). Apply them to `Point`
and `Book`.

### Task 5.9
A `Stack` class and a child `LimitedStack(max_size)`
that overrides `push` and raises an exception on overflow.
Additionally — `CountingStack`, which counts the number of `push` calls.

### Task 5.10
A game: `Item` (name, weight) → `Weapon` (damage), `Potion` (healing),
`Armor` (defense). An `Inventory` class: `add`, `total_weight()`,
`of_type(cls)` (via `isinstance`), `strongest_weapon()`.

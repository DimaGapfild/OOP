# Практичні завдання до розділу 12

**Тип завдань:** реалізувати патерн проєктування для заданої ситуації.

Вимоги до **кожної** задачі:
1. клієнтський код залежить від абстракції, а не від конкретних класів;
2. docstring у класах; назва патерну — у коментарі/докстрінгу;
3. покажіть **розширення без зміни існуючого коду**;
4. щонайменше 3 тести.

> **Інструменти для тестів.** Використовуйте стандартний інструмент своєї мови:
> - **Python** — `pytest` (`def test_...(): assert ...`) або вбудований `unittest`;
> - **JavaScript / TypeScript** — вбудовані `node:test` + `node:assert` (Node 18+) або `Jest` / `Vitest`;
> - **C++** — `GoogleTest` або `Catch2`; для швидких перевірок — `assert` із `<cassert>`.
>
> Порада: покрийте звичайний випадок, граничний (порожньо, нуль, межа) і некоректні дані.

---

### Задача 12.1 — Singleton
`AppConfig` — єдиний об'єкт налаштувань: `set(key, value)`,
`get(key, default=None)`. Двічі створені екземпляри — один об'єкт.
Додайте `reset()` для тестів.

### Задача 12.2 — Factory
`ShapeFactory` із реєстром: `register(kind, creator)` і
`create(kind, *args)`. Вбудовані: `circle`, `rect`, `square`.
Невідомий вид → `ValueError`. Новий вид додається без зміни фабрики.

### Задача 12.3 — Builder
`PizzaBuilder`: `size()`, `sauce()`, `topping()`, `build()`.
`build()` перевіряє обов'язкові параметри (розмір, соус) і повертає
незмінну `Pizza`. Клас `PizzaDirector` з готовими рецептами.

### Задача 12.4 — Adapter
Сторонні класи: `LegacySensor.read_fahrenheit()` та
`OldLogger.write_line(level, text)`. Адаптуйте їх до
інтерфейсів `TemperatureSensor.celsius()` і `Logger.log(msg)`.

### Задача 12.5 — Decorator
`Beverage` (`description()`, `cost()`), базові `Espresso`, `Tea`,
декоратори `Milk`, `Sugar`, `Caramel`. Показати довільний порядок
і повторне застосування (подвійний цукор).

### Задача 12.6 — Strategy
`Sorter(strategy)` зі стратегіями `BubbleSort`, `InsertionSort`,
`MergeSort`. Стратегію можна змінити під час виконання;
додайте стратегію, що лічить кількість порівнянь.

### Задача 12.7 — Observer
`Stock(symbol, price)` — суб'єкт. Підписники: `PriceLogger`
(пише історію) та `AlertObserver(threshold)` (повідомляє при
перевищенні порога). Підтримати `attach` / `detach`.

### Задача 12.8 — Command
`TextEditor` (текст) і команди `InsertCommand(pos, text)`,
`DeleteCommand(pos, length)`. `History`: `execute`, `undo`, `redo`.

### Задача 12.9 — State
Замовлення: `New → Paid → Shipped → Delivered`; скасувати можна
лише з `New` та `Paid`. Реалізуйте кожен стан окремим класом,
недопустимий перехід → `InvalidTransition`.

### Задача 12.10 — Міні-проєкт «Магазин»
Поєднайте патерни: `ProductFactory` (книга/електроніка з різним
ПДВ), `Cart` (Observer: слухачі отримують події зміни), знижки
(Strategy) із необов'язковим пакуванням-декоратором, `History` команд
додавання/видалення з `undo`.

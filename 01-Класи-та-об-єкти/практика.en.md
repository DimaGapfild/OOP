# Practice Tasks for Chapter 1

**Task type:** describe a simple class from a verbal specification and
demonstrate how it works.

Requirements for **every** task:
1. a class with a constructor and at least 2 methods;
2. a docstring in the class;
3. a demonstration: create 2–3 objects and show that their data is independent;
4. 3 checks using `assert`.

---

### Task 1.1
A `Point` class — a point on a plane (x, y).
Methods: `distance_to(other)` — the distance to another point,
`move(dx, dy)` — shift the point, `is_origin()` — whether it is the origin.

### Task 1.2
A `Rectangle` class — a rectangle (width, height).
Methods: `area()`, `perimeter()`, `is_square()`.

### Task 1.3
A `Counter` class — a counter that starts at zero.
Methods: `increment()`, `decrement()` (not below 0), `reset()`,
`value()`.

### Task 1.4
A `Book` class — title, author, number of pages, current page.
Methods: `read(n)` — read n pages (not beyond the last one),
`progress()` — percentage read, `is_finished()`.

### Task 1.5
A `Student` class — a surname and a list of grades.
Methods: `add_grade(g)`, `average()`, `best()`, `has_debt()`
(there is a grade below 60).

### Task 1.6
A `LightSwitch` class — a switch (on/off state).
Methods: `toggle()`, `is_on()`, and a counter of the number of toggles,
`switches()`.

### Task 1.7
A `Stack` class — a stack of integers.
Methods: `push(x)`, `pop()` (returns `None` if the stack is empty),
`peek()`, `size()`, `is_empty()`.

### Task 1.8
A `Product` class — name, price, discount in percent (0 by default).
Methods: `final_price()`, `set_discount(p)` (0..100), `total(qty)`.

### Task 1.9
A `Car` class — brand, tank capacity, current fuel level,
consumption per 100 km. Methods: `refuel(l)`, `drive(km)` — returns
the distance actually driven (limited by the fuel), `range_left()`.

### Task 1.10
A `Library` class that holds a list of `Book` objects (from task 1.4).
Methods: `add(book)`, `find(author)` — a list of the author's books,
`total_pages()`, `longest()`.

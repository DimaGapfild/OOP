# Розділ 1. Класи та об'єкти

## 1.1 Навіщо потрібне ООП

У процедурному підході **дані окремо, функції окремо**:

```python
book = {"title": "Кобзар", "pages": 320}

def is_long(b):
    return b["pages"] > 300
```

Нічого не гарантує, що в словнику є ключ `pages`, а функція `is_long`
ніяк не прив'язана до «книжки». ООП **об'єднує дані й поведінку**
в одну сутність — **об'єкт**.

Переваги підходу:

- код моделює предметну область (студент, рахунок, фігура);
- дані захищені від довільних змін;
- легко повторно використовувати й розширювати код;
- великі програми діляться на невеликі незалежні частини.

## 1.2 Клас і об'єкт

- **Клас** — опис (шаблон, тип): які дані має сутність і що вона вміє.
- **Об'єкт (екземпляр)** — конкретне втілення класу з власними даними.

Аналогія: клас — креслення будинку, об'єкт — збудований будинок.
За одним кресленням можна збудувати багато будинків.

| Поняття | Що це | Приклад |
|---------|-------|---------|
| Клас | тип даних | `Book` |
| Об'єкт | екземпляр класу | `Book("Кобзар", 320)` |
| Атрибут (поле) | дані об'єкта | `title`, `pages` |
| Метод | функція, що належить класу | `is_long()` |

## 1.3 Мінімальний клас

```python
class Book:
    """Книга з назвою та кількістю сторінок."""

    def __init__(self, title: str, pages: int):
        self.title = title
        self.pages = pages

    def is_long(self) -> bool:
        return self.pages > 300


b1 = Book("Кобзар", 320)
b2 = Book("Енеїда", 180)
print(b1.title, b1.is_long())   # Кобзар True
print(b2.title, b2.is_long())   # Енеїда False
```

Кожен об'єкт має **власний набір атрибутів**: зміна `b1.pages` не
впливає на `b2`.

```python
b1.pages = 100
print(b1.is_long(), b2.pages)   # False 180
```

## 1.4 self

`self` — посилання на **поточний об'єкт**. Це перший параметр кожного
методу; при виклику Python підставляє його сам:

```python
b1.is_long()            # те саме, що Book.is_long(b1)
```

## 1.5 Об'єкти — посилання

Змінна зберігає **посилання** на об'єкт, а не сам об'єкт.

```python
a = Book("Кобзар", 320)
b = a                    # b вказує на ТОЙ САМИЙ об'єкт
b.pages = 1
print(a.pages)           # 1
print(a is b)            # True — той самий об'єкт
c = Book("Кобзар", 1)
print(a is c)            # False — різні об'єкти (хоч дані однакові)
```

Щоб отримати незалежну копію — створюють новий об'єкт
(або `copy.copy`, `copy.deepcopy`).

## 1.6 Функції для роботи з об'єктами

```python
type(b1)                     # <class '__main__.Book'>
isinstance(b1, Book)         # True
hasattr(b1, "title")         # True
getattr(b1, "pages")         # 320
vars(b1)                     # {'title': 'Кобзар', 'pages': 320}
```

## 1.7 Об'єкти в об'єктах

Атрибут може бути іншим об'єктом — так будують складніші моделі:

```python
class Library:
    def __init__(self):
        self.books: list[Book] = []

    def add(self, book: Book) -> None:
        self.books.append(book)

    def total_pages(self) -> int:
        return sum(b.pages for b in self.books)
```

## 1.8 Порівняння з іншими мовами

| Python | JavaScript | C++ |
|--------|-----------|-----|
| `class A:` | `class A {` | `class A { public: ... };` |
| `__init__(self)` | `constructor()` | `A() {}` |
| `self.x` | `this.x` | `this->x` або `x` |
| `A(1)` | `new A(1)` | `A a(1);` |
| `b = a` (посилання) | `b = a` (посилання) | `A b = a;` — **копія**! |

У C++ присвоєння об'єкта створює копію; посилання потребує `A& b = a;`
або вказівника.

# Practice Tasks for Chapter 12

**Task type:** distribute responsibilities among classes using the GRASP
principles and justify the choice.

Requirements for **every** task:
1. state in the class docstring which GRASP principle is applied and why;
2. do not break encapsulation (no "extra" getters just so outside code can compute);
3. docstrings in classes and methods;
4. 3 checks using `assert`.

---

### Task 12.1 — Information Expert
`Product(name, price)`, `OrderLine(product, qty)`, `Order(discount_pct)`.
The `subtotal()` computation belongs to the line, `total()` to the order.
No external "calculator".

### Task 12.2 — Creator
`Course(title, capacity)` creates an `Enrollment` in the method `enroll(student)`.
A duplicate and overflow → `ValueError`. `students()` returns
a tuple.

### Task 12.3 — Controller
The `TodoList` model knows nothing about the UI. `TodoController.handle(command)`
accepts the strings `add text`, `done N`, `list` and returns a text
reply; the function `run_ui(controller, lines)` is a thin UI with no logic.

### Task 12.4 — Low Coupling
`Customer → Address → City`. `Shipping.cost(customer)` must not
know about `Address` and `City`: add a delegate `city_name()`.
Show that `Shipping` works with any object that has `city_name()`.

### Task 12.5 — High Cohesion
There is a "dump" class `Helper` (mean, median, `slugify`, word count,
leap year, days in a month). Split it into `Stats`, `TextTools`,
`Calendar`; each class can be described in one sentence without "and".

### Task 12.6 — Polymorphism
A ticket's price depends on its type: `Adult`, `Child` (50 %), `Senior` (70 %).
A function `total(tickets, base)` with no `if` on the type. Add `Group(size)`
(a 10 % discount) **without changing** `total`.

### Task 12.7 — Pure Fabrication
`Invoice(number, amount)` must not know how to save itself. Create an
artificial `InvoiceRepository`: `save`, `find` (`None` if absent),
`total_amount()`; saving the same number again replaces the record.

### Task 12.8 — Indirection
A `ChatRoom` between `ChatUser`s: users do not know about each other.
`say(text)` broadcasts to everyone except the sender; after `leave` messages
no longer arrive; `say` outside a room → `RuntimeError`.

### Task 12.9 — Protected Variations
`Money.convert(to, provider)` depends on the `RateProvider` interface.
Implementations: `FixedRates` and `CachedRates` (a wrapper that counts calls to
the source). The client code does not change.

### Task 12.10 — Cinema: A Responsibility Table
Design seat booking: `Session` (seats, price), `PriceRule`
(`Standard`, `Vip`), `Booking`, `BookingRepository`,
`BookingController`. Write a "responsibility → class → GRASP principle"
table in a comment. A taken or non-existent seat is an error that the
controller turns into the reply `{"ok": False, "error": ...}`.

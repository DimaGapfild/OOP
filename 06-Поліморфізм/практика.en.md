# Practice Tasks for Chapter 6

**Task type:** write code that works with objects of different types through
a shared interface.

Requirements for **every** task:
1. client code **contains no** `type(x) == ...` checks
   (unless the task requires otherwise);
2. docstrings in classes and functions;
3. a demonstration on a list of objects of different classes;
4. 3 checks using `assert`.

---

### Task 6.1
A `Shape` with `area()` and `perimeter()`; children `Circle`, `Rectangle`,
`Triangle`. Functions `total_area(shapes)`, `largest(shapes)`
and sorting by area.

### Task 6.2
A notification system: `Notifier.send(to, text)` — children `EmailNotifier`,
`SmsNotifier` (truncates the text to 20 characters), `PushNotifier`.
A function `broadcast(notifiers, to, text)` returns the list of messages
sent.

### Task 6.3
Duck typing: classes `Duck`, `Robot`, `Person` **with no common
ancestor**, each has `quote()`. A function `chorus(objs)` collects the quotes;
objects without `quote` are skipped.

### Task 6.4
Payment methods: `Card` (1.5 % fee), `PayPal` (3 % + 5 UAH),
`Crypto` (0.5 %). A single method `pay(amount)` returns
`(charged, fee)`. A function `cheapest(methods, amount)`.

### Task 6.5
`TextFormatter.format(s)`: `UpperFormatter`, `ReverseFormatter`,
`TrimFormatter`, `CensorFormatter(words)`. A `Pipeline` class
applies a list of formatters one after another.

### Task 6.6
Ad hoc polymorphism. A function `describe(x)` via
`functools.singledispatch` for `int`, `float`, `str`, `list`, `dict`
and a default. A `Calculator` class with `add(*args)`: numbers
are summed, strings are concatenated.

### Task 6.7
`Media.play()` and `duration()`: `Song`, `Podcast`, `Video`.
A `MediaQueue` class adds media, returns the total duration
and plays everything in turn (the result is a list of strings).

### Task 6.8
Parametric polymorphism: a function `largest(items, key=None)`
(numbers, strings, a custom class with `__lt__`) and a class `TypedList(type)`
that accepts only elements of the given type (`TypeError` otherwise).

### Task 6.9
`Document.render(elements)`: `PlainText`, `Markdown`, `Html` — the same
set of elements (a heading, paragraphs, a list) is output
in different formats.

### Task 6.10
A game: `Character.attack()` returns damage; children `Warrior`,
`Mage` (spends mana; hits weakly without mana), `Archer` (a miss
is decided by a passed-in "dice" function — for testing). A function
`battle(team, hp)` — how many rounds the team needs to destroy
an enemy with `hp`.

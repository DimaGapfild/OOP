# Практичні завдання до розділу 6

**Тип завдань:** написати код, що працює з різнотипними об'єктами через
спільний інтерфейс.

Вимоги до **кожної** задачі:
1. клієнтський код **не містить** перевірок `type(x) == ...`
   (де задача не вимагає іншого);
2. docstring у класах і функціях;
3. демонстрація на списку об'єктів різних класів;
4. 3 перевірки через `assert`.

---

### Задача 6.1
`Shape` з `area()` та `perimeter()`; нащадки `Circle`, `Rectangle`,
`Triangle`. Функції `total_area(shapes)`, `largest(shapes)`
і сортування за площею.

### Задача 6.2
Система сповіщень: `Notifier.send(to, text)` — нащадки `EmailNotifier`,
`SmsNotifier` (обрізає текст до 20 символів), `PushNotifier`.
Функція `broadcast(notifiers, to, text)` повертає список надісланих
повідомлень.

### Задача 6.3
Duck typing: класи `Duck`, `Robot`, `Person` **без спільного
предка**, кожен має `quote()`. Функція `chorus(objs)` збирає цитати;
об'єкти без `quote` пропускаються.

### Задача 6.4
Платіжні методи: `Card` (комісія 1.5 %), `PayPal` (3 % + 5 грн),
`Crypto` (0.5 %). Єдиний метод `pay(amount)` повертає
`(списано, комісія)`. Функція `cheapest(methods, amount)`.

### Задача 6.5
`TextFormatter.format(s)`: `UpperFormatter`, `ReverseFormatter`,
`TrimFormatter`, `CensorFormatter(words)`. Клас `Pipeline`
послідовно застосовує список форматувальників.

### Задача 6.6
Ситуативний поліморфізм. Функція `describe(x)` через
`functools.singledispatch` для `int`, `float`, `str`, `list`, `dict`
і за замовчуванням. Клас `Calculator` з `add(*args)`: числа
складаються, рядки склеюються.

### Задача 6.7
`Media.play()` та `duration()`: `Song`, `Podcast`, `Video`.
Клас `MediaQueue` додає медіа, повертає загальну тривалість
і відтворює все по черзі (результат — список рядків).

### Задача 6.8
Параметричний поліморфізм: функція `largest(items, key=None)`
(числа, рядки, власний клас із `__lt__`) і клас `TypedList(type)`,
що приймає лише елементи заданого типу (`TypeError` інакше).

### Задача 6.9
`Document.render(elements)`: `PlainText`, `Markdown`, `Html` — один і
той самий набір елементів (заголовок, абзаци, список) виводиться
в різних форматах.

### Задача 6.10
Гра: `Character.attack()` повертає шкоду; нащадки `Warrior`,
`Mage` (витрачає ману; без мани б'є слабо), `Archer` (промах
визначає передана функція-«кубик» — для тестів). Функція
`battle(team, hp)` — скільки раундів потрібно команді, щоб знищити
ворога з `hp`.

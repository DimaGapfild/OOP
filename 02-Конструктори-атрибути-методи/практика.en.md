# Practice Tasks for Chapter 2

**Task type:** use a constructor with default values,
class attributes, `@classmethod` and `@staticmethod`.

Requirements for **every** task:
1. all attributes are created in the constructor;
2. docstrings in the class and methods;
3. a demonstration with 2–3 objects;
4. at least 3 tests.

> **Testing tools.** Use the standard tool for your language:
> - **Python** — `pytest` (`def test_...(): assert ...`) or the built-in `unittest`;
> - **JavaScript / TypeScript** — the built-in `node:test` + `node:assert` (Node 18+), or `Jest` / `Vitest`;
> - **C++** — `GoogleTest` or `Catch2`; for quick checks, `assert` from `<cassert>`.
>
> Tip: cover a normal case, an edge case (empty, zero, limit), and invalid input.

---

### Task 2.1
An `Employee` class — name, salary (10000 by default).
The class attribute `count` counts the objects created.
A method `raise_salary(percent)`.

### Task 2.2
A `Temperature` class — degrees Celsius.
`@classmethod from_fahrenheit(f)`, `@classmethod from_kelvin(k)`,
a method `to_fahrenheit()`, `@staticmethod is_valid(c)`.

### Task 2.3
A `Date` class — year, month, day.
`@classmethod from_string("YYYY-MM-DD")`,
`@staticmethod is_leap(year)`, a method `days_in_month()`.

### Task 2.4
A `MathUtils` class with static methods only:
`gcd(a, b)`, `is_prime(n)`, `factorial(n)`, `fibonacci(n)`.
(No objects need to be created.)

### Task 2.5
A `Config` class with a class attribute `defaults` (a dictionary) and
per-instance settings. The method `get(key)` returns
the instance's value or, if there is none, the default value.
Show that changing one object does not affect another.

### Task 2.6
A `Ticket` class — each new object automatically gets
a unique, increasing `id` (via a class attribute). The method
`Ticket.created()` returns the number of tickets created.

### Task 2.7
A `Money` class — an amount in kopiykas (an integer).
`@classmethod from_float(x)` and `from_string("12.50")`,
methods `to_float()`, `__str__` in the format `12.50 UAH`.

### Task 2.8
A `Person` class — first name and last name.
`@classmethod from_full_name("Ivan Koval")`,
methods `full_name()`, `initials()` (e.g. `I.K.`).

### Task 2.9
A `Pizza` class with a constructor (`size=30`, `toppings=None`).
The method `add(topping)` returns `self` (method chaining),
the method `price()` = the base price for the size + 10 per topping.
Show that two objects do not share one list of toppings.

### Task 2.10
A `Registry` class with a class-level list of all created instances.
Methods: `Registry.all()`, `Registry.find(name)`,
`Registry.clear()`; each instance has a name.

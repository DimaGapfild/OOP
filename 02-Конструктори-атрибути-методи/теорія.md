## 2.1 Конструктор `__init__`

Конструктор викликається автоматично під час створення об'єкта і
задає його початковий стан.

```python
class Employee:
    def __init__(self, name: str, salary: float = 10000):
        self.name = name
        self.salary = salary

e1 = Employee("Коваль")             # salary = 10000
e2 = Employee("Бондар", salary=25000)
```

Гарні практики:

- усі атрибути створювати **в `__init__`** (щоб бачити повний «склад» об'єкта);
- значення за замовчуванням — **незмінні** (`None`, числа, рядки);
- **небезпечно** — змінні типи за замовчуванням:

```python
def __init__(self, items=[]):       # ПОМИЛКА: один список на всі об'єкти
    self.items = items

def __init__(self, items=None):     # правильно
    self.items = [] if items is None else list(items)
```

## 2.2 Атрибути екземпляра та класу

```python
class Employee:
    company = "ТОВ «Софт»"          # атрибут КЛАСУ — спільний
    count = 0

    def __init__(self, name):
        self.name = name            # атрибут ЕКЗЕМПЛЯРА — власний
        Employee.count += 1
```

| | Атрибут класу | Атрибут екземпляра |
|---|---|---|
| Де оголошується | у тілі класу | в `__init__` через `self` |
| Скільки копій | одна на клас | по одній на об'єкт |
| Доступ | `Employee.count` або `e.count` | `e.name` |

Пастка: присвоєння через екземпляр **створює новий атрибут екземпляра**
і «затінює» атрибут класу:

```python
e1.company = "Інша"               # тільки в e1
print(Employee.company)           # ТОВ «Софт» — не змінилось
```

## 2.3 Методи екземпляра, класу та статичні

```python
class Temperature:
    def __init__(self, celsius: float):
        self.celsius = celsius

    def to_fahrenheit(self) -> float:          # метод екземпляра (self)
        return self.celsius * 9 / 5 + 32

    @classmethod
    def from_fahrenheit(cls, f: float):        # метод класу (cls)
        return cls((f - 32) * 5 / 9)

    @staticmethod
    def is_valid(celsius: float) -> bool:      # статичний (без self/cls)
        return celsius >= -273.15


t = Temperature.from_fahrenheit(212)           # 100.0 °C
```

| Вид | Перший параметр | Має доступ до | Типове призначення |
|-----|----------------|---------------|--------------------|
| звичайний | `self` | об'єкта й класу | робота з даними об'єкта |
| `@classmethod` | `cls` | класу | альтернативні конструктори |
| `@staticmethod` | немає | нічого | допоміжні функції, що логічно «живуть» у класі |

## 2.4 Альтернативні конструктори

Python не має перевантаження конструкторів. Замість цього —
`@classmethod`-«фабрики»:

```python
class Date:
    def __init__(self, y, m, d):
        self.y, self.m, self.d = y, m, d

    @classmethod
    def from_string(cls, s: str):              # "2026-10-05"
        y, m, d = map(int, s.split("-"))
        return cls(y, m, d)
```

`cls` (а не жорстко `Date`) дозволяє підкласам теж користуватися фабрикою.

## 2.5 Ланцюжки викликів (fluent interface)

Якщо метод повертає `self`, виклики можна з'єднувати:

```python
class Pizza:
    def __init__(self):
        self.toppings = []

    def add(self, t):
        self.toppings.append(t)
        return self                    # <- ключове

p = Pizza().add("сир").add("гриби").add("шинка")
```

## 2.6 Порівняння з іншими мовами

| Задача | Python | JavaScript | C++ |
|--------|--------|-----------|-----|
| Значення за замовчуванням | `def f(x=0)` | `constructor(x = 0)` | `A(int x = 0)` |
| Атрибут класу | у тілі класу | `static count = 0;` | `static int count;` (+ визначення поза класом, або `inline`) |
| Метод класу | `@classmethod` | `static create()` | `static A create()` |
| Кілька конструкторів | фабрики | фабрики | **перевантаження** конструкторів |

# Practice Tasks for Chapter 8

**Task type:** design classes that contain other objects;
decide where there is composition and where aggregation.

Requirements for **every** task:
1. state the type of relationship (composition / aggregation) in the class docstring;
2. parts that the "whole" owns are created by the "whole" itself;
3. outside code must not be able to break the internal state;
4. 3 checks using `assert`.

---

### Task 8.1
A `Car` **has** an `Engine` (composition). `Engine`: power,
`start()`, `stop()`, state. `Car`: `start()`, `stop()` (delegate),
`drive(km)` — only with the engine running (`RuntimeError` otherwise),
a mileage counter.

### Task 8.2
A `Computer` consists of `CPU`, `RAM`, `Disk` (each part has
a name, a characteristic, a price). Methods `total_price()`, `spec()`.

### Task 8.3
Aggregation: `Library` and `Book`. Books exist independently; `Reader.borrow(
library, title)` moves a book from the library to the reader, `give_back`
returns it. Show that the books live on after the library is destroyed.

### Task 8.4
Many-to-many aggregation: `Employee` and `Team`. An employee
can be in several teams; `add_member` / `remove_member`
maintain both sides of the relationship. `Team.total_salary()`.

### Task 8.5
Composition: `Order` owns `OrderLine(product, qty)` lines.
`add(product, qty)` merges identical products; `total()`;
`lines()` returns a tuple (read-only).

### Task 8.6
Delegation: a `Stack` **contains** a list (does not inherit!).
Methods `push`, `pop`, `peek`, `size`; the object must not have
`append`, `insert`, `sort`.

### Task 8.7
Dependency injection: `Transport` (an interface) →
`SmtpTransport`, `FakeTransport` (remembers messages).
`Notifier(transport)` sends notifications; in a test,
verify that the message reached `FakeTransport`.

### Task 8.8
A component model: `Health`, `Mover`, `Attacker`. An `Entity` class
consists of a set of components. Build an `Orc` (all three),
a `Tower` (Health + Attacker), a `Rock` (Health). A function `attack(a, b)`
works only if `a` has an `Attacker` and `b` has `Health`.

### Task 8.9
Recursive composition: `File(name, size)` and `Folder(name)`
(can contain files and folders). Methods `total_size()`,
`count_files()`, `find(name)` → the path `root/dir/file` or `None`.

### Task 8.10
A `Playlist` contains `Song` objects. Methods `shallow_copy()` and
`deep_copy()`. Prove with a test: changing a song's title in a shallow
copy changes the original, in a deep one it does not.

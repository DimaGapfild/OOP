# Практичні завдання до розділу 4

**Тип завдань:** реалізувати клас із перевантаженими операторами
і контейнерними методами.

Вимоги до **кожної** задачі:
1. `__init__` із валідацією (`ValueError`);
2. `__str__` і `__repr__`;
3. оператори мають повертати **нові** об'єкти, не змінюючи операндів;
4. при несумісному типі — `NotImplemented`;
5. щонайменше 3 тести.

> **Інструменти для тестів.** Використовуйте стандартний інструмент своєї мови:
> - **Python** — `pytest` (`def test_...(): assert ...`) або вбудований `unittest`;
> - **JavaScript / TypeScript** — вбудовані `node:test` + `node:assert` (Node 18+) або `Jest` / `Vitest`;
> - **C++** — `GoogleTest` або `Catch2`; для швидких перевірок — `assert` із `<cassert>`.
>
> Порада: покрийте звичайний випадок, граничний (порожньо, нуль, межа) і некоректні дані.

---

### Задача 4.1
Клас `Vector` (2D): `+`, `-`, `*` (на число, зліва й справа),
унарний `-`, `abs()`, `==`. Скалярний добуток — метод `dot()`.

### Задача 4.2
Клас `Fraction`: автоматичне скорочення, знаменник ≠ 0;
`+`, `-`, `*`, `/`, `==`, `<` (та решта порівнянь через
`total_ordering`), `float()`.

### Задача 4.3
Клас `Time` (год, хв, сек з нормалізацією): `+`, `-` (не нижче 0),
порівняння, `str` у форматі `ГГ:ХХ:СС`, `hash`.

### Задача 4.4
Клас `Matrix`: `+`, `*` (число і матриця), `[i][j]` через
`__getitem__` (кортеж `m[i, j]`), `==`, `str`. Перевіряти розміри.

### Задача 4.5
Клас `Complex`: `+`, `-`, `*`, `abs()`, `conjugate()`, `==`,
підтримка операцій із дійсними числами (`c + 2`, `2 + c`).

### Задача 4.6
Клас `Polynomial` (коефіцієнти від a₀): `+`, `*`,
`__call__(x)`, `__str__` у вигляді `1 + 2x^2`, `degree`.

### Задача 4.7
Клас `Playlist`: `len()`, `[i]` (включно зі зрізами), `in`,
`for`, `bool()`, `+` (об'єднання), `+=` для додавання пісні.

### Задача 4.8
Клас `Version` (`"1.2.10"`): порівняння за числовими
компонентами (`1.2.10 > 1.2.9`), `==`, `hash`, `str`;
список версій сортується через `sorted()`.

### Задача 4.9
Клас `Money` (копійки, валюта): `+`, `-` (лише одна валюта,
інакше `ValueError`), `*` на число, порівняння, `bool` (ненульова),
підтримка `sum(list_of_money)` через `__radd__` із `0`.

### Задача 4.10
Клас `Bag` (мультимножина): `bag["a"]` — кількість (0, якщо немає),
`bag["a"] = n`, `len` — сума кількостей, `in`, `+` (злиття),
`==`, обхід по елементах із повторами.

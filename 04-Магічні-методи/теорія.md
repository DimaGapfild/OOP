# Розділ 4. Магічні методи та перевантаження операторів

## 4.1 Ідея

Магічні (dunder — «double underscore») методи дозволяють власним
класам поводитися як вбудовані типи: підтримувати `+`, `==`, `len()`,
`print()`, `for ... in`, `[]` тощо. Ви їх **не викликаєте напряму** —
Python викликає їх сам.

**Python**

```python
a + b        # a.__add__(b)
len(x)       # x.__len__()
x[3]         # x.__getitem__(3)
```

**JavaScript** — оператори перевантажити не можна; працюють лише
кілька «спеціальних» методів:

```js
`${x}`       // x.toString()
a < b        // a.valueOf() < b.valueOf()
for (const v of x) {}   // x[Symbol.iterator]()
```

**C++** — оператори є звичайними функціями з іменем `operator…`:

```cpp
a + b        // a.operator+(b) або operator+(a, b)
a == b       // a.operator==(b)
x[3]         // x.operator[](3)
```

## 4.2 Рядкове подання об'єкта

| Метод | Для кого | Виклик |
|-------|----------|--------|
| `__str__` | користувача | `print(obj)`, `str(obj)`, f-рядки |
| `__repr__` | розробника (однозначно) | REPL, `repr(obj)`, елементи в списках |

**Python**

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):  return f"({self.x}; {self.y})"
    def __repr__(self): return f"Point({self.x}, {self.y})"
```

**JavaScript**

```js
class Point {
    constructor(x, y) {
        [this.x, this.y] = [x, y];
    }

    toString() { return `(${this.x}; ${this.y})`; }
}

console.log(`${new Point(1, 2)}`);   // (1; 2)
```

**C++** — рядкове подання задають оператором виводу `<<`:

```cpp
#include <iostream>

struct Point {
    double x, y;
};

std::ostream& operator<<(std::ostream& out, const Point& p) {
    return out << "(" << p.x << "; " << p.y << ")";
}

std::cout << Point{1, 2};            // (1; 2)
```

Правило: `__repr__` має виглядати як код, що відтворює об'єкт.
Якщо є лише `__repr__`, `print` теж його використає.

## 4.3 Арифметичні оператори

| Оператор | Метод | Праве доповнення |
|----------|-------|------------------|
| `+` | `__add__` | `__radd__` |
| `-` | `__sub__` | `__rsub__` |
| `*` | `__mul__` | `__rmul__` |
| `/` | `__truediv__` | `__rtruediv__` |
| `//` | `__floordiv__` | |
| `%` | `__mod__` | |
| `**` | `__pow__` | |
| `-x` | `__neg__` | |
| `abs(x)` | `__abs__` | |
| `+=` | `__iadd__` (інакше `__add__`) | |

**Python**

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, k):                  # v * 3
        return Vector(self.x * k, self.y * k)

    def __rmul__(self, k):                 # 3 * v
        return self * k
```

**JavaScript** — замість операторів звичайні методи:

```js
class Vector {
    constructor(x, y) {
        [this.x, this.y] = [x, y];
    }

    add(other) {
        return new Vector(this.x + other.x, this.y + other.y);
    }

    mul(k) {                               // v.mul(3)
        return new Vector(this.x * k, this.y * k);
    }
}
```

**C++**

```cpp
struct Vector {
    double x, y;

    Vector operator+(const Vector& other) const {
        return {x + other.x, y + other.y};
    }

    Vector operator*(double k) const {     // v * 3
        return {x * k, y * k};
    }
};

Vector operator*(double k, const Vector& v) {   // 3 * v — вільна функція
    return v * k;
}
```

Якщо операція не підтримується з таким типом, повертають
`NotImplemented` (а не кидають виняток) — Python спробує `__r…__`
в іншого операнда:

**Python**

```python
def __add__(self, other):
    if not isinstance(other, Vector):
        return NotImplemented
    ...
```

**JavaScript** — типи перевіряють вручну і кидають виняток:

```js
add(other) {
    if (!(other instanceof Vector)) {
        throw new TypeError("очікується Vector");
    }
    // ...
}
```

**C++** — непідтримувану комбінацію типів відкидає **компілятор**:
якщо `operator+` для пари типів не оголошено, код не скомпілюється.

> **Різниця між мовами: оператор для «непідготовленого» класу.**
> Що буде, якщо застосувати `+` чи `*` до об'єктів, для яких ці
> оператори не визначено?
>
> ```python
> Vector(1, 2) + Vector(3, 4)   # TypeError: unsupported operand type(s) for +
> 3 * Vector(1, 2)              # TypeError (якщо немає __rmul__)
> ```
>
> ```js
> new Vector(1, 2) + new Vector(3, 4);   // "[object Object][object Object]" — рядок!
> 3 * new Vector(1, 2);                  // NaN
> ```
>
> ```cpp
> Vector{1, 2} + Vector{3, 4};  // помилка компіляції: invalid operands
> ```
>
> JavaScript перетворює об'єкти на рядки чи числа й **не повідомляє про
> помилку** — неправильне значення «тече» далі програмою.

## 4.4 Порівняння

| Оператор | Метод |
|----------|-------|
| `==` | `__eq__` |
| `!=` | `__ne__` (за замовчуванням — заперечення `__eq__`) |
| `<` `<=` `>` `>=` | `__lt__` `__le__` `__gt__` `__ge__` |

Достатньо `__eq__` і `__lt__` + декоратор `functools.total_ordering` —
решту він згенерує.

**Важливо:** якщо визначили `__eq__`, об'єкт перестає бути хешованим.
Для використання в множинах/ключах словника визначте і `__hash__`:

**Python**

```python
def __hash__(self):
    return hash((self.x, self.y))
```

**JavaScript** — немає `__hash__`: `Set` і `Map` порівнюють об'єкти
**за посиланням**. Для пошуку за значенням використовують рядковий ключ:

```js
const key = (p) => `${p.x},${p.y}`;
const seen = new Set([key(p1)]);
seen.has(key(new Point(1, 2)));    // true
```

**C++** — для `std::unordered_set` потрібні `operator==` і
спеціалізація `std::hash`:

```cpp
#include <functional>

struct Point {
    int x, y;
    bool operator==(const Point&) const = default;
};

template <>
struct std::hash<Point> {
    size_t operator()(const Point& p) const {
        return std::hash<int>{}(p.x) ^ (std::hash<int>{}(p.y) << 1);
    }
};
```

(хеш має бути узгоджений з `__eq__`, а об'єкт — по суті незмінним).

## 4.5 Контейнерні методи

| Вираз | Метод |
|-------|-------|
| `len(x)` | `__len__` |
| `x[i]` | `__getitem__` |
| `x[i] = v` | `__setitem__` |
| `del x[i]` | `__delitem__` |
| `v in x` | `__contains__` |
| `for v in x` | `__iter__` |
| `bool(x)`, `if x:` | `__bool__` (інакше `__len__`) |

**Python**

```python
class Playlist:
    def __init__(self, *songs):
        self._songs = list(songs)

    def __len__(self):            return len(self._songs)
    def __getitem__(self, i):     return self._songs[i]   # і зрізи також
    def __contains__(self, s):    return s in self._songs
```

**JavaScript**

```js
class Playlist {
    #songs;

    constructor(...songs) {
        this.#songs = songs;
    }

    get length()       { return this.#songs.length; }
    at(i)              { return this.#songs.at(i); }
    has(s)             { return this.#songs.includes(s); }
    [Symbol.iterator]() { return this.#songs[Symbol.iterator](); }
}
```

**C++**

```cpp
#include <algorithm>
#include <string>
#include <vector>

class Playlist {
public:
    Playlist(std::initializer_list<std::string> songs) : songs(songs) {}

    size_t size() const                        { return songs.size(); }
    const std::string& operator[](size_t i) const { return songs[i]; }
    bool contains(const std::string& s) const {
        return std::find(songs.begin(), songs.end(), s) != songs.end();
    }
    auto begin() const { return songs.begin(); }   // для range-for
    auto end() const   { return songs.end(); }

private:
    std::vector<std::string> songs;
};
```

Навіть лише з `__getitem__` об'єкт можна обходити циклом `for`.

## 4.6 Викликані об'єкти

**Python**

```python
class Polynomial:
    def __init__(self, *coeffs):          # a0 + a1*x + a2*x²
        self.coeffs = coeffs

    def __call__(self, x):
        return sum(c * x ** i for i, c in enumerate(self.coeffs))

p = Polynomial(1, 0, 2)    # 1 + 2x²
print(p(3))                # 19
```

**JavaScript** — функції самі є об'єктами, тож замикання замінює
`__call__`:

```js
function polynomial(...coeffs) {           // a0 + a1*x + a2*x²
    return (x) => coeffs.reduce((sum, c, i) => sum + c * x ** i, 0);
}

const p = polynomial(1, 0, 2);   // 1 + 2x²
console.log(p(3));               // 19
```

**C++** — функтор з `operator()`:

```cpp
#include <cmath>
#include <vector>

class Polynomial {
public:
    Polynomial(std::initializer_list<double> c) : coeffs(c) {}

    double operator()(double x) const {
        double sum = 0;
        for (size_t i = 0; i < coeffs.size(); ++i) {
            sum += coeffs[i] * std::pow(x, i);
        }
        return sum;
    }

private:
    std::vector<double> coeffs;
};

Polynomial p{1, 0, 2};   // 1 + 2x²
std::cout << p(3);       // 19
```

## 4.7 Порівняння з іншими мовами

| Можливість | Python | JavaScript | C++ |
|------------|--------|-----------|-----|
| Перевантаження операторів | магічні методи | **немає** (методи `add()`, `equals()`) | `operator+`, `operator==`, ... |
| Рядкове подання | `__str__` | `toString()` | `operator<<` |
| Індексація | `__getitem__` | немає (методи `get(i)`) | `operator[]` |
| Обхід `for` | `__iter__` | `[Symbol.iterator]` | `begin()`/`end()` |
| Виклик як функції | `__call__` | функція/метод | `operator()` |

У JS єдині «неявні» перетворення — `toString()`, `valueOf()` (дозволяє
`<`, `>` та арифметику) і `Symbol.iterator`.

## 4.8 Питання для самоперевірки

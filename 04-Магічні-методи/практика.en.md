# Practice Tasks for Chapter 4

**Task type:** implement a class with overloaded operators
and container methods.

Requirements for **every** task:
1. `__init__` with validation (`ValueError`);
2. `__str__` and `__repr__`;
3. operators must return **new** objects without modifying the operands;
4. for an incompatible type — `NotImplemented`;
5. 3 checks using `assert`.

---

### Task 4.1
A `Vector` class (2D): `+`, `-`, `*` (by a number, on the left and right),
unary `-`, `abs()`, `==`. The dot product is a `dot()` method.

### Task 4.2
A `Fraction` class: automatic reduction, denominator ≠ 0;
`+`, `-`, `*`, `/`, `==`, `<` (and the other comparisons via
`total_ordering`), `float()`.

### Task 4.3
A `Time` class (hours, minutes, seconds with normalization): `+`, `-` (not below 0),
comparison, `str` in the format `HH:MM:SS`, `hash`.

### Task 4.4
A `Matrix` class: `+`, `*` (a number and a matrix), `[i][j]` via
`__getitem__` (the tuple `m[i, j]`), `==`, `str`. Check the dimensions.

### Task 4.5
A `Complex` class: `+`, `-`, `*`, `abs()`, `conjugate()`, `==`,
support for operations with real numbers (`c + 2`, `2 + c`).

### Task 4.6
A `Polynomial` class (coefficients starting from a₀): `+`, `*`,
`__call__(x)`, `__str__` in the form `1 + 2x^2`, `degree`.

### Task 4.7
A `Playlist` class: `len()`, `[i]` (including slices), `in`,
`for`, `bool()`, `+` (concatenation), `+=` to add a song.

### Task 4.8
A `Version` class (`"1.2.10"`): comparison by numeric
components (`1.2.10 > 1.2.9`), `==`, `hash`, `str`;
a list of versions can be sorted with `sorted()`.

### Task 4.9
A `Money` class (kopiykas, currency): `+`, `-` (a single currency only,
otherwise `ValueError`), `*` by a number, comparison, `bool` (non-zero),
support for `sum(list_of_money)` via `__radd__` with `0`.

### Task 4.10
A `Bag` class (a multiset): `bag["a"]` — the count (0 if absent),
`bag["a"] = n`, `len` — the sum of counts, `in`, `+` (merge),
`==`, iteration over elements with repetitions.

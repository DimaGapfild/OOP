# Chapter 4. Magic Methods and Operator Overloading

## 4.1 The Idea

Magic (dunder — "double underscore") methods let your own
classes behave like built-in types: support `+`, `==`, `len()`,
`print()`, `for ... in`, `[]`, and so on. You **do not call them directly** —
Python calls them itself.

```python
a + b        # a.__add__(b)
len(x)       # x.__len__()
x[3]         # x.__getitem__(3)
```

## 4.2 Representing an Object: `__str__` and `__repr__`

| Method | For whom | Invoked by |
|--------|----------|-----------|
| `__str__` | the user | `print(obj)`, `str(obj)`, f-strings |
| `__repr__` | the developer (unambiguous) | the REPL, `repr(obj)`, elements inside lists |

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):  return f"({self.x}; {self.y})"
    def __repr__(self): return f"Point({self.x}, {self.y})"
```

Rule: `__repr__` should look like code that recreates the object.
If only `__repr__` exists, `print` uses it too.

## 4.3 Arithmetic Operators

| Operator | Method | Reflected counterpart |
|----------|--------|-----------------------|
| `+` | `__add__` | `__radd__` |
| `-` | `__sub__` | `__rsub__` |
| `*` | `__mul__` | `__rmul__` |
| `/` | `__truediv__` | `__rtruediv__` |
| `//` | `__floordiv__` | |
| `%` | `__mod__` | |
| `**` | `__pow__` | |
| `-x` | `__neg__` | |
| `abs(x)` | `__abs__` | |
| `+=` | `__iadd__` (otherwise `__add__`) | |

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, k):                  # v * 3
        return Vector(self.x * k, self.y * k)

    def __rmul__(self, k):                 # 3 * v
        return self * k
```

If the operation is not supported with that type, return
`NotImplemented` (do not raise an exception) — Python will then try `__r…__`
on the other operand:

```python
def __add__(self, other):
    if not isinstance(other, Vector):
        return NotImplemented
    ...
```

## 4.4 Comparison

| Operator | Method |
|----------|--------|
| `==` | `__eq__` |
| `!=` | `__ne__` (by default, the negation of `__eq__`) |
| `<` `<=` `>` `>=` | `__lt__` `__le__` `__gt__` `__ge__` |

`__eq__` and `__lt__` plus the `functools.total_ordering` decorator are enough —
it generates the rest.

**Important:** once you define `__eq__`, the object stops being hashable.
To use it in sets or as dictionary keys, define `__hash__` as well:

```python
def __hash__(self):
    return hash((self.x, self.y))
```

(the hash must be consistent with `__eq__`, and the object must be essentially immutable).

## 4.5 Container Methods

| Expression | Method |
|------------|--------|
| `len(x)` | `__len__` |
| `x[i]` | `__getitem__` |
| `x[i] = v` | `__setitem__` |
| `del x[i]` | `__delitem__` |
| `v in x` | `__contains__` |
| `for v in x` | `__iter__` |
| `bool(x)`, `if x:` | `__bool__` (otherwise `__len__`) |

```python
class Playlist:
    def __init__(self, *songs):
        self._songs = list(songs)

    def __len__(self):            return len(self._songs)
    def __getitem__(self, i):     return self._songs[i]   # slices work too
    def __contains__(self, s):    return s in self._songs
```

Even with only `__getitem__`, an object can be traversed with a `for` loop.

## 4.6 Callable Objects: `__call__`

```python
class Polynomial:
    def __init__(self, *coeffs):          # a0 + a1*x + a2*x²
        self.coeffs = coeffs

    def __call__(self, x):
        return sum(c * x ** i for i, c in enumerate(self.coeffs))

p = Polynomial(1, 0, 2)    # 1 + 2x²
print(p(3))                # 19
```

## 4.7 Comparison with Other Languages

| Feature | Python | JavaScript | C++ |
|---------|--------|-----------|-----|
| Operator overloading | magic methods | **none** (methods `add()`, `equals()`) | `operator+`, `operator==`, ... |
| String representation | `__str__` | `toString()` | `operator<<` |
| Indexing | `__getitem__` | none (methods `get(i)`) | `operator[]` |
| `for` traversal | `__iter__` | `[Symbol.iterator]` | `begin()`/`end()` |
| Call as a function | `__call__` | a function/method | `operator()` |

In JS the only "implicit" conversions are `toString()`, `valueOf()` (which enables
`<`, `>` and arithmetic) and `Symbol.iterator`.
